# Moon Mission | Artemis II

A multi-page educational website about NASA's Artemis II mission, the history of lunar exploration, and Canada's contributions to space exploration. Created as a web development project for CS1033 at Western University.

**[View the live website](https://cs1033.gaul.csd.uwo.ca/~apostea/webassign/index.html)**

## About the project

The website explores the Artemis II crewed lunar flyby and places it in the broader history of Moon exploration. It also highlights Canadian astronaut Jeremy Hansen, Canada's space robotics contributions, and connections to London, Ontario.

## Pages and features

- **Home (`index.html`)**: An introduction to Artemis II, its crew, mission milestones, and the origins of the Artemis name.
- **History (`history.html`)**: An overview of lunar exploration, from early observations and the Space Race to Apollo and Artemis, with section navigation and a course-provided mission countdown.
- **Canada's Role (`canadasrole.html`)**: Canada's space robotics, Jeremy Hansen, and Western University's connection to space research.
- **Space Pics (`spacepics.html`)**: A curated gallery featuring the Artemis II crew, an Earthset photograph, and the Orion crew capsule.
- **References (`references.html`)**: Image sources and attributions.

The site uses a shared navigation menu, a consistent visual style, linked images, and informational content across its pages.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Use the navigation menu to explore the other pages.

No installation or build process is required. Some linked external resources or course-provided features may require an internet connection.
